## Summary

Integrates Circuit 2 (geographic location verification) into `contracts/zk-location-verifier` using Soroban's native **BN254 host cryptographic primitives** (issue #1809). Planters keep their GPS coordinates private — the circuit proves membership in the approved Northern Nigeria geohash boundary off-chain, and the contract verifies the resulting Groth16 proof on-chain.

### What changed

- **On-chain Groth16 verifier** (`groth16` module): real BN254 operations via `env.crypto().bn254()` — `g1_is_on_curve` point validation, `Bn254Fr::from_bytes` scalar reduction, `g1_mul`/`g1_msm`-style `vk_x` construction and a 4-pair `pairing_check` implementing `e(-A,B)·e(α,β)·e(vk_x,γ)·e(C,δ) == 1`. Off-curve G1 points are rejected before any host arithmetic so malformed proofs return a clean contract error instead of trapping.
- **Public `verify_location_proof(submitter, proof, input) -> bool`**: binds the public boundary commitment to the embedded Merkle root, verifies the proof, and atomically consumes the location nullifier. `submitter.require_auth()` prevents third parties from spending somebody else's nullifier.
- **Replay protection**: spent nullifiers are written to persistent storage (30-day TTL) with a `SpentNullifier` audit record; `is_nullifier_spent` is exposed as a view helper. A replay fails with `LOCATION_NULLIFIER_ALREADY_SPENT` and never writes state.
- **Off-chain auditability**: `get_verification_key_hash()` (SHA-256 of the whole embedded VK) and `get_boundary_commitment()` are read-only. The VK and boundary root are compile-time constants, per spec Requirement 5.
- **Error-code standard compliance**: the three new errors use this crate's allocated block (`global_code(54, n)` = `0x370001..0x370003`), guarded by compile-time assertions. No existing error value was renumbered.
- **Types/docs**: added `LocationProof`, `LocationProofInput`, `SpentNullifier`; updated `docs/contracts/interface.md`; enabled `rlib` output so integration tests can link the crate (matching sibling contracts).
- **Test fixes**: repaired two pre-existing test bugs that prevented the suite from compiling/running (`&(i % 9) as u32` cast and `u8` overflow in the `proof_digest` helper).

The embedded VK is a structural placeholder, matching the approach already used by the sibling `zk-verifier` contract, and is clearly documented as such. Replacing the constants with the real Circuit 2 trusted-setup output needs no code change.
