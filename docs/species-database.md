# Searchable Species Database (#1622)

Specification for a searchable species database covering tree species available for sponsorship.

## Species Data Attributes
- **Native Range:** Geographic origin and regional distribution.
- **Growth Rate:** Expected growth speed and maturity timeline.
- **Ecological Role:** Ecosystem support, soil stability, and habitat contribution.
- **Typical CO2 Absorption:** Estimated carbon sequestration rate per tree.

## Acceptance Criteria & Structure
- **Species Detail Page:** Displays species photos alongside structured botanical and impact data cards.
- **Navigation Links:** Accessible directly from individual tree profiles and the species filter view.
- **Data Sources:** Sourced from authoritative botanical databases (e.g., Kew POWO, USDA PLANTS).
