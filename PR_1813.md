## Summary

Implements the Soroban custom error code standard requested in issue #1813.

Before this change, nearly every contract numbered its `#[contracterror]` variants from `1`, so the same on-chain `u32` meant different things in different contracts (codes `1..=13` were reused by ~35 enums, and `90..=206` by many more). An SDK client receiving `{ contractId, error: 1 }` could not reliably resolve the failure, which blocks predictable frontend error handling.

### What changed

- **`contracts/harvesta-errors/src/standard.rs` (new)** — dependency-free (`core`-only, `no_std`) implementation of the standard:
  - 16-bit namespace + 16-bit local code layout (`global_code`, `namespace_of`, `local_of`, `origin_of`);
  - `ErrorRange` with inclusive-interval helpers;
  - `CRATE_NAMES` / `CRATE_ERROR_RANGES`: a disjoint 65,536-value block for each of the 56 workspace crates;
  - compile-time `const` assertions that all ranges are valid and pairwise disjoint, plus that the shared registry stays below the namespace boundary.
- **`contracts/harvesta-errors/src/lib.rs`** — crate-level documentation of the standard, `pub mod standard`, exhaustive machine-readable registries (`ALL_HARVESTA_ERRORS`, `ALL_GOVERNANCE_ERRORS`, `ALL_NFT_ERRORS`, `ALL_FARMER_ERRORS`) for tooling/frontend generation, and 13 unit tests (code uniqueness, range containment, pinned legacy values, table/namespace consistency, encode/decode round-trips).
- **`docs/contracts/error-code-standard.md` (new)** — the full standard: rules, encoding diagram, the complete 56-crate allocation table, contract and TypeScript decoding examples, and a migration backlog for the legacy colliding enums.
- **`docs/contracts/interface.md`** — link to the new standard from the contract interface catalog.

### Compatibility / zero regression

No existing enum variant was renumbered. The deployed shared codes (`HarvestaError` `1..=118`, and the auxiliary enums) are untouched, so existing frontend message maps keep working. The new blocks start at `0x010000`, safely above every legacy code. Existing duplicate/error enums are recorded in the migration backlog rather than changed blindly, which keeps this PR free of ABI-breaking churn.

### Verification

- `cargo fmt --manifest-path contracts/harvesta-errors/Cargo.toml -- --check` → clean (exit 0).
- 13/13 unit tests pass (standalone `rustc --test` harness with a stubbed `#[contracterror]` attribute, because this environment cannot reach `static.crates.io` to fetch the pinned `soroban-sdk` 27.x sources; `cargo test -p harvesta-errors` therefore cannot resolve dependencies locally). A full `cargo test` in CI with network access will run the same tests through Cargo.
- `git diff --check` → clean.

Closes #1813
